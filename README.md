# Lost Lotus

## Описание
**Lost Lotus** - Игра где ты попадаешь в абсолютно другой мир. Твоя задача: Выбраться обратно в реальность, мир манит к себе но на самом деле он опасен. А дальше играй сам не буду спойлерить :)

## Примичания
Игра находится в разработке, могут быть баги, в исходном коде!
